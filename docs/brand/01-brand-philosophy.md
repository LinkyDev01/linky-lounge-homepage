## 1. 이름과 위계

```
레이지클럽 (lazy-club.com)                      ← 브랜드. 회원·관리·인증의 장기 단위
 ├─ 레이지데이 북클럽 (lazyday-bookclub.com)     ← 기수제 독서모임. 트래픽은 아직 가장 크다
 ├─ 원데이 토크 · 무비토크                        ← 단회 모임 (『브람스를 좋아하세요...』『시지프 신화』『호프』)
 ├─ 4주 과정                                     ← '불안을 건너 고요로...'(안동민) · '비로소, 나를 쥐어짜지 않는 법'(천고든)
 ├─ 동민과 고든 커피앤바                          ← 두 사람의 이름을 건 자리. 유머가 허용된 유일한 하위 브랜드
 └─ 제품                                         ← 코스터 · 머그 · 프린트 티셔츠
공간: 링키라운지 (linkylounge.com, 사당역 도보 3분)   ← 모임이 열리는 곳. 별도 사이트, 지시 없이 수정 금지
법인: 주식회사 링키 (대표 안동민)                    ← 푸터 사업자 정보의 주체
```

**레이지클럽이 상위, 북클럽은 그 안의 프로그램 하나다** (운영자 2026-09-02 "엄밀하게 레이지클럽 안에
레이지데이 북클럽이 있어"). 회원·인증·관리처럼 **오래 남는 것의 이름·도메인·바깥에 보이는 설명은
레이지클럽 기준**이고, 접수·일정·기수처럼 **프로그램 단위**는 각자의 이름을 그대로 쓴다.
코드 트리(`app/(main)/lazyday/**` 가 북클럽 도메인의 본체)는 배선의 문제라 이름을 따라 옮기지 않는다.

이름 표기: **레이지클럽** / **레이지데이 북클럽** / **원데이 토크**(원데이 클럽 아님) / 기수는 **"4기"**.
"레이지데이"라는 이름은 '게으른 날' — 성취 압박·완독 인증·출석 스트릭 같은 것과 원리적으로 충돌한다.

## 2. 한 문장

> 저마다 다른 삶의 궤적 속 불협화음이 예술의 본질을 관통하여 하나의 선율이 되는 순간을 소망합니다.

레이지클럽 푸터·OG 설명에 쓰는 브랜드 문장이다(운영자 2026-08-04 원문). 북클럽 랜딩의 짝은
"사유의 불협화음이 본질을 관통하는 선율이 되는 순간을 믿습니다." — 같은 신조의 두 표기다.

## 3. 신조 — 무엇을 믿는가

### 결 (Habitus)

> 우리가 정의하는 '결'은 한 사람이 살아온 환경과 경험을 통해 체화된 무의식적인 판단과 반응의 패턴,
> 즉 한 사람의 아비투스(Habitus)입니다.

"결이 맞는다"는 취향의 일치가 아니라 **서로의 아비투스가 정교하게 맞물려 움직이는 상태**다.
한 사람이 문장 앞에 멈춰 설 때 다른 이가 그 침묵을 함께 견디는 것, 누가 말을 보태고 누가 응시할지가
개입 없이 정해지는 것 — 원고는 이것을 **'결의 공명'** 이라 부른다. 처음 만난 사이에도 즉시 작동하고,
오래 알아도 결이 다르면 닿을 수 없는 영역이다.

### 불균형의 균형 (Dissonant Harmony)

> 비슷한 결을 가진 이들이 모였다고 해서, 결코 같은 결론에 도달할 필요는 없습니다.

바우하우스의 정갈한 비대칭처럼, 각자의 세계에서 단련된 사유가 부딪힐 때 생기는 **불협화음**이
오히려 본질을 관통하는 하나의 선율이 되는 순간을 믿는다. "무색무취하게 고개만 끄덕이는 느슨한
공감의 자리가 아닙니다." — 이것이 레이지데이가 지키는 **대화의 문법**이다.
디자인 원칙 "축 정렬 + 1요소 이탈", "불균형의 균형"(2026-08-03)은 이 신조의 시각 번역이다.

### 선별은 초대의 절차다

모든 멤버는 참여에 앞서 인터뷰를 한다 — 허들이 아니라 **"서로의 결을 미리 엿보며, 우리의 대화가
앞으로 어떻게 얽혀 나갈지 함께 가늠해 보는 첫 출발점"**(브랜드 3문단 원문). 이 절차 자체가 브랜드 장치다.
⚠ 2026-09-02 확정: **가입(계정)은 상시 공개**다. 선별은 없어지는 게 아니라 **기수 입회로 자리를 옮긴다** —
계정이 있다고 북클럽 기수에 들어오는 것이 아니다.

## 4. 태도 — 어떻게 서 있는가

| 태도 | 뜻 | 화면에서 |
|---|---|---|
| **절제 = 자신감** | 설득 장치를 걷어낸다. 여백과 침묵이 지위를 만든다 (레퍼런스: Aesop, The Row — 하이엔드의 결) | 후기 숫자·혜택·잔여석·마감 임박 연출 없음. 홈에 "신청" 단어 없음 |
| **홈은 인덱스지 홍보가 아니다** | 워크룸프레스 구조를 차용한 이유. 발명형 히어로 없이 내비 아래 곧바로 콘텐츠 | 레이지클럽 홈 = 모임·제품·사람·일정·기록의 목록 |
| **신조의 공유** | 상품 설명이 아니라 "우리가 믿는 것"에 공명하게 | 모임 설명이 카피가 아니라 원고 |
| **무표정한 유머** | 정색하고 던지는 농담. 같은 농담은 반복하지 않는다 (M3, 2026-08-10) | 거북이 트랙 "굳이 세어보면 2027년까지 N초 남았습니다." / 커피앤바 "네그로니는 없습니다" / 사람 약력의 자기 풍자 |
| **변하지 않기 때문에** | 표시를 더하지 않고 반응만 준다 (2026-08-06 라운드 58: 써클에 버튼 옷을 입힌 안 전부 기각) | 그림자·밑줄로만 반응. 라운드·색면·보더 버튼 0 |
| **보류는 거절이 아니라 연기** | 섹션·기능은 지우지 않고 렌더만 끈다 (`SHOW_GOODS` 선례) | 고아 컴포넌트 보존 규율 |
| **증거로 말한다** | "됐을 것" 금지. 스크린샷·실측·curl 마커 | 철칙 3 |

## 5. 하지 않는 것

전 관점 합의(`docs/community-spec-2026-07.md` §2-6)와 개편 결정을 합친 목록. **이유가 브랜드다.**

- 마케팅 상투어 · 과장 형용사 · 자기계발 어휘 · 감탄사 · 이모지
- 후기·숫자·혜택으로 설득하기, 잔여석 카운터, 마감 임박 연출, 추천인 리워드
- 게이미피케이션(배지·챌린지·리더보드·포인트·출석 스트릭), 독서 진도·완독 인증 — '게으른 날'과 충돌
- 공개 피드·타임라인·좋아요·댓글, 상시 단체 채팅, 공개 멤버 디렉토리, 별점·온라인 후기 폼
- 발제문(레이지 노트) 사전 공개 — 오프라인이 먼저 소비되어야 한다
- 유채색 UI · 라운드 · 색면 버튼 · 그림자(레이지클럽 범위) — 색은 콘텐츠(책 표지·제품 사진·그래픽)에서만 발생
- 타인 템플릿 전재, 레퍼런스의 메뉴명·콘텐츠·이미지 복제 (구조·수치만 차용)
- 상태를 **색으로만** 말하기 — 글자 라벨·채움 농도·해칭으로 함께 말한다(색각 이상·흑백에서 사라지지 않게)

## 6. 언어 — 어떻게 말하는가

정본 `docs/redesign/05-copy-elements.md` 톤 규칙. 전 페이지 불변.

- **어미**: 합쇼체 평서 단일. 해요체·청유·감탄 금지. 부정 선언("~하지 않습니다")로 경계를 긋되 섹션당 1회
- **인칭**: 독자 직접 호명 금지. 자격 규정형("~하는 사람들"). 브랜드 자칭 "우리"
- **어휘**: 지적 한자어(사유·궤적·화두·밀도) + 물성 고유어 동사(부딪히다·벼리다·엿보다).
  은유 필드: 직물(결) / 소리(불협화음) / 빛·시선(윤곽) / 금속(벼리다)
- **리듬**: 장문 뒤 단문 선언. 강조는 대구·역설로
- **표기**: "4기", 날짜 "9.7", 책은 『』, `keep-all`. 홈에서 "신청" 단어 금지(상세는 "구매하기")
- **예외 두 곳**: ① 홈 리스트 이미지 페어 카피는 워크룸 원문 뉘앙스(도록체 명사형·한다체) ② 커피앤바는
  손글씨 서체 위에 유머가 허용된다 — 둘 다 운영자 확정 예외이고 다른 데로 번지지 않는다
- **손님에게 말할 때**(폼·안내문): 사실대로. 즉시 접수를 약속하지 않고("순차 확인 후 연락"),
  실패는 감추지 않고 구제 경로(카카오톡 채널)를 준다
