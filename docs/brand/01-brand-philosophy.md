# 01 · 브랜드 철학 — 레이지클럽은 무엇이고 왜 이런 모양인가

> 정본: 설계 대화 기록 `docs/redesign/01-decisions.md`(2026-08-03~11, 라운드 1~134) ·
> `docs/DECISIONS.md` 2026-08-12~ (레이지클럽 행) · 카피 규범 `docs/redesign/05-copy-elements.md` ·
> 위계 `docs/DECISIONS.md` 2026-09-02. 인용문은 전부 운영자 원문 그대로다.
>
> ⚠ **북클럽 신조(결·아비투스·불균형의 균형·인터뷰=초대)는 이 문서에 없다** — 그건 하위 프로그램의
> 원고이고 `lazyday/philosophy.md` 가 정본이다. 2026-09-03 에 이 문서에서 걷어냈다: 북클럽 철학을
> 레이지클럽에 씌우면 레이지클럽의 정체(상점 문법을 입은 허브 + 무표정 유머)가 안 보인다.

## 1. 이름과 위계

```
레이지클럽 (lazy-club.com)                      ← 브랜드. 회원·관리·인증의 장기 단위
 ├─ 레이지데이 북클럽 (lazyday-bookclub.com)     ← 기수제 독서모임. 트래픽은 아직 가장 크다
 ├─ 원데이 토크                                  ← 단회 모임 (브람스를 좋아하세요... · 시지프 신화 · 호프)
 ├─ 4주 과정                                     ← '불안을 건너 고요로...'(안동민) · '비로소, 나를 쥐어짜지 않는 법'(천고든)
 ├─ 동민과 고든 커피앤바                          ← 두 사람의 이름을 건 대화 자리. 손글씨체·3색·유머가 허용된 유일한 하위 브랜드
 └─ 제품                                         ← 코스터 · 머그 · 프린트 티셔츠
공간: 링키라운지 (linkylounge.com, 사당역 도보 3분)   ← 모임이 열리는 곳. 별도 사이트, 지시 없이 수정 금지
법인: 주식회사 링키 (대표 안동민)                    ← 푸터 사업자 정보의 주체
```

**레이지클럽이 상위, 북클럽은 그 안의 프로그램 하나다** (운영자 2026-09-02 "엄밀하게 레이지클럽 안에
레이지데이 북클럽이 있어"). 회원·인증·관리처럼 **오래 남는 것의 이름·도메인·바깥에 보이는 설명은
레이지클럽 기준**이고, 접수·일정·기수처럼 **프로그램 단위**는 각자의 이름을 그대로 쓴다.
코드 트리(`app/(main)/lazyday/**` 가 북클럽 도메인의 본체)는 배선의 문제라 이름을 따라 옮기지 않는다.

이름 표기: **레이지클럽** / **레이지데이 북클럽** / **원데이 토크**(원데이 클럽·무비토크 아님, 2026-08-21 통일) /
기수는 **"4기"**. 내비는 여섯 개의 명사 — 전체보기 · 모임 · 제품 · 사람 · 일정 · 기록.

## 2. 한 문장

> 저마다 다른 삶의 궤적 속 불협화음이 예술의 본질을 관통하여 하나의 선율이 되는 순간을 소망합니다.

레이지클럽 푸터·OG 설명에 쓰는 브랜드 문장이다(운영자 2026-08-04 원문, 어미는 2026-08-18 "소망합니다"로
최종). 북클럽의 짝("…사유의 궤적 속 불협화음이 고전의 본질을…")과 **교차 복사 금지** — 같은 신조의 두 표기다.

## 3. 컨셉 — 왜 이런 모양인가

**한 줄**: workroompress.kr(출판사 상점)의 골격을 실측해 옮기고, 그 위에 독서모임을 **상품처럼 진열**한
브랜드 허브. 북클럽 랜딩이 콰이어트 에디토리얼이라면 레이지클럽은 **상점 문법 + 무표정 유머**다.

- **홈은 인덱스지 홍보가 아니다.** 히어로 없이 내비 아래 곧바로 목록(모임·제품·사람·일정·기록). 모집은 notice
  항목 하나. 홈에 "신청"이라는 단어가 없고, 상세에서만 **"구매하기"**. 섹션 제목은 링크가 아니다 — 이동은 내비로만.
- **상품화의 부조화를 일부러 살린다** (2026-08-04 라운드 7 "워크룸식 '상품화 부조화'는 살리되 UX 불편은 제거").
  지난 기수는 sold out 상품으로 진열, 티셔츠는 NEW ARRIVAL, 확정 전 가격은 `₩999,999`, 카트·저장 버튼.
  독서모임에 커머스 옷을 입혔을 때 생기는 어색함이 곧 태도다. 단 손님을 불편하게 하지 않는다 —
  주소 안 받고 이름·전화만(티켓형 결제).
- **구조·수치는 실측, 콘텐츠는 고유.** 원본 CSS 를 curl 로 열어 13.2px/1.5 · 좌우 15px · 15컬럼 · 2:1 병치를
  그대로 옮기고(`08-workroom-transplant.md`), 메뉴명·문구·이미지는 전부 우리 것 — 복제 시비 원천 차단.
  "레퍼런스는 기억으로 흉내 내지 말고 CSS 를 직접 열어 볼 것"(2026-08-07 라운드 67).
- **느리다.** 내비 로고 10초에 한 바퀴, 거북이는 400ms/프레임(보간 거부 — 운영자 "느릿느릿 뻣뻣한 모션이
  더 좋아"), 1년짜리 트랙, 60초 유휴 화면. '레이지'가 이름값을 한다.
- **정성이 과한 곳에 브랜드가 산다.** 설득 장치(숫자·혜택·마감 임박)는 없다. 대신 농담 하나에 물리 적분과
  실측이 들어간다 — "무표정·발견형·불필요하게 고퀄"(2026-08-10 M3).

## 4. 문법

**시각** — 정본 `02-design-system.md`.
- **백지 + 잉크 + 괘선.** 유채색·라운드·보더 버튼·그림자 전부 0. 상자 대신 괘선, 버튼 대신 밑줄 텍스트.
  색은 콘텐츠(책 표지·제품 사진·로고)에서만 발생한다.
- **위계는 자리가 만든다.** 내비·라벨·본문·푸터가 같은 13.2px·같은 색·같은 무게. 예외는 리스트 제목 18px 하나.
- **구성요소 전량 노출.** 미구현 기능도 지우지 않고 "준비 중" 토스트. **보류는 거절이 아니라 연기** —
  섹션은 지우지 않고 렌더만 끈다(`SHOW_GOODS` 플래그 한 줄로 부활한 선례, 2026-08-07 라운드 82).
- **상태를 색으로만 말하지 않는다.** 글자 라벨·채움 농도·해칭이 함께 간다. 문구가 색을 가리키면 안 된다.

**표기** (2026-08-21 일괄 정비).
- 제품은 **품절**, 모임은 **마감** — 영문 sold out 폐지. 품절·마감이 가격 자리를 차지한다(진적색 글자).
- 제목은 `원데이 토크, 브람스를 좋아하세요...` — 『』 감싸기 폐지, 모임명 뒤에 작품. 카드 상단 라벨은
  종류가 아니라 **진행자 이름**. 진행자 미확정이면 임의 배정 금지 → "레이지데이 북클럽".
- `' · '`(띄어쓴 가운뎃점) 연결 금지 — 쓸 거면 소괄호. 붙여 쓴 열거용(`이름·성별·나이`)은 다른 용법이라 유지.
- 링크가 아니면 화살표(↗)도 뗀다. 한 번 쓴 사람 슬러그(핸들)는 다른 사람에게 주지 않는다.

**언어** — 정본 `docs/redesign/05-copy-elements.md`.
- 합쇼체 평서 단일. 독자 직접 호명 금지("~하는 사람들"). 자칭 "우리". 감탄사·이모지·과장 형용사·마케팅 상투어 금지.
- **홈 리스트 이미지 페어 카피만 도록체**(명사형·한다체) — "타인의 낯선 시선을 기꺼이 환대하며",
  "멤버들이 남긴 문장들". 합쇼체 규정의 유일한 홈 예외(2026-08-04).
- 손님에게 말할 때는 사실대로. 실패는 감추지 않고 구제(신청 내용 복사·카카오톡)를 준다. "유실보다 중복이 낫다."

**모션** — 세 규율(2026-08-10 M1~M3).
- **기존 요소만 움직인다** / **화면당 하나·모션 없이도 완결·1회성** / **무표정·발견형·불필요하게 고퀄, 같은 농담 반복 금지.**
- **물리는 진짜 물리.** 도망 버튼은 60프레임 적분(추진→속도제곱 저항→벽 반발→용수철), 로고 낙하는 굴림
  Δθ=이동거리/반지름, 거북이 복귀는 감쇠 스프링(K=70·C=11). 손으로 그린 곡선 없음.
  운영자 "물리법칙에 가깝게", "프레임을 끊어서 더 딱딱하게".

## 5. 위트 — 정색하고, 과하게 잘 만든다

농담이 **카피가 아니라 장치**다. 문장은 건조하고, 힘은 실측·물리·페이지 간 연결에 들어간다. 한 번만, 정해진 자리에서만.

| 장치 | 무엇 | 왜 서는가 |
|---|---|---|
| **거북이 트랙** (일정 하단 sticky) | 2027-01-01 까지 초 단위 카운트다운. *"굳이 세어보면 2027년까지 12,530,761초 남았습니다."* 30초 머물면 *"올해의 42초를 거북이를 보는 데 쓰셨습니다."* 5분이면 *"5분째 보고 있는 당신을 위해 거북이가 완주를 서두르고 있습니다."* | 화면의 거북이는 명백히 기어가는 중 — 정색한 거짓말. 2행이 붙어야 "페이지가 자기를 관찰하는 농담"이 된다(2026-08-08 라운드 111). 10초는 숫자가 작아 농담이 안 섰다 → 30초. 머문 사람에게만 보이고 첫인상은 안 흐린다 |

## 6. 지향점과 결정 방식

- **설득하지 않는다.** 후기 숫자·혜택·잔여석·마감 임박 없음. 채널 친구 수 같은 숫자도 밖에 내걸지 않는다.
- **손님에게는 사실대로.** 즉시 접수를 약속하지 않고("순차 확인 후 연락"), 실패를 감추지 않는다.
- **라운드 단위 대조 루프.** 눈대중 금지 — 실측값·스크린샷·curl 마커로 판정한다. 시안은 실배치로 보여준다.
- **카피는 운영자 소유.** 내가 쓴 임시본(예: "버튼은 도망쳤지만 신청서는 도망가지 않습니다")은 운영자 원문이
  오면 갈아끼운다. 사실 진술은 컨피그 정정 지시다.
- **보류는 연기.** 지운 게 아니라 남긴다 — 코드·CSS·데이터는 보존하고 렌더만 끈다.

## 9. 못 잡으면 이렇게 틀린다

- **북클럽 원고(결·아비투스·선별=초대)를 레이지클럽에 씌운다** — 그건 하위 프로그램의 신조다.
  레이지클럽의 정체는 상점 문법을 입은 허브. (2026-09-03 에 이 문서가 그렇게 쓰여 있었다 — 걷어냈다)
- 위트를 **문체**로만 보고 **장치**를 못 본다 → 합쇼체만 지키고 링크·물리·카운트다운을 장식으로 뺀다
- 무표정을 차가움으로 읽고 유머를 뺀다 / 반대로 유머를 카피로 여기저기 뿌린다
- 모션을 "예쁘게"로 → 규율은 기존 요소·1회·발견형. 보간해서 부드럽게 만들면 틀린다
- 워크룸을 따라 그린다 → 실측·대조 루프, 콘텐츠는 고유
- "따뜻하게" 하려고 해요체·이모지를 넣는다 / 버튼(보더·색면·라운드)을 만든다 / 숫자로 설득한다
