# 02 · 디자인 시스템 — 레이지클럽 화면은 왜 이렇게 생겼나

> 정본: `CLAUDE.md` §9(규율) · `docs/redesign/02-design-tokens.md`(토큰 원칙) ·
> `docs/redesign/08-workroom-transplant.md`(실측값) · 코드 `app/(main)/lazyclub/home.module.css`(현재 값).
> 수치가 어긋나면 **코드가 정본**이다 — 이 문서는 값을 옮겨 적은 요약이지 새 출처가 아니다.
> 북클럽 랜딩(lazyday)은 별도 시스템(§10) — 두 시스템은 공존하고 섞지 않는다.

---

## 1. 세 원리

1. **백지 + 잉크 + 괘선.** UI 는 무채색이다. 색은 콘텐츠(책 표지·제품 사진·그래픽·로고)에서만 발생한다.
   상자 대신 괘선, 버튼 대신 텍스트 링크, 라운드 0 · 그림자 0 · 색면 0.
2. **구조·수치는 실측, 콘텐츠는 고유.** 홈 골격은 workroompress.kr 을 curl 로 실측해 옮겼다(08).
   임의 스케일·눈대중 금지. 메뉴명·문구·이미지는 전부 우리 것 — 복제 시비를 원천 차단한다.
3. **위계는 배치가 만든다.** 내비·라벨·본문·푸터가 같은 크기(13.2px)·같은 색이다. 크기·굵기·색으로
   위계를 세우지 않고 자리(순서·괘선·여백)로 세운다. 예외는 리스트 제목 18px 하나.

## 2. 색

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--ink` | `#1a1208` | 글자·괘선·도트·채움 버튼 배경. 순흑이 아니라 따뜻한 잉크 |
| `--paper` | `#f7f3ee` | 배경(오트). 인트로·유휴 오버레이도 이 색 |
| `--ph-gray` | `#ece5da` | 플레이스홀더·슬라이드 바탕 |
| 보조 글자 | `#6d6459` | 폼 안내문 등 한 단계 낮은 글 |
| 헤어라인 | `rgba(26,18,8,.18~.22)` | 얇은 구분선 |
| 배지 회색 | `#9b9184` | NEW ARRIVAL (브라운야드 실측) |
| 품절 | `#a22525` | OUT OF STOCK 글자 — 색으로만 말하지 않고 **글자**가 함께 있다 |

**허용된 유채색(예외 목록 — 늘리려면 운영자 승인)**
- 로고 원본 풀컬러(파비콘·OG·개편 홈) — "색을 지나치게 제한할 필요 없다"(2026-08-04)
- 일정 페이지 카테고리 3색: 북클럽 `#d2691e` / 원데이 토크 `#845d5e` / 무비토크 `#96ab9b` — 범례 글자와 함께
- 제품 컬러 칩(제품 사진에서 실측 추출 — UI 색이 아니라 제품의 색)
- 커피앤바 3색: `#f49c3c` · `#845c64` · `#94ac9c` — 그 페이지 원본 조판의 색, 밖으로 나가지 않는다
- 관리 화면 `crm.module.css` 는 같은 잉크·오트 + `--paper2 #f0e9e0`·`--muted #8a7660`, 유채색 0

**상태를 색으로만 말하지 않는다** (§9): 차단=잉크 채움 / 예약=사선 해칭 / 선택=테두리 / '정상·확인 필요' 글자.
문구가 색을 가리키면 안 된다("주황 슬롯 클릭" 금지).

## 4. 레이아웃

- **전폭, 좌우 15px.** 컨테이너 max-width 없음. 15컬럼 `1fr` 그리드, gap 15px(헤더·푸터), 모바일 4컬럼 gap 10.
- **헤더 fixed 2행** — 1행 원형 로고(45px, 10초 시계 회전) + 계정·카트·검색 아이콘(자체 드로잉 SVG 16px,
  strokeWidth 1.2), 2행 좌 내비 6(전체보기·모임·제품·사람·일정·기록) / 우 '레이지데이 북클럽'(새 탭).
  본문 `padding-top 100px`. 모바일도 같은 2행 — **햄버거 금지**.
- **브레이크포인트 단일 720px**(원문 실측). 검증은 3뷰포트 **390 / 768 / 1280** — 768 은 데스크톱 구성이다.
- 홈 병치: 좌 모임 리스트 2열 / 우 북클럽 기수 진열, `2:1`, 세로 괘선 1px. ≤720 세로 스택(북클럽이 위).
- 리스트 항목: 5컬럼 grid, 썸네일 2/5 폭 **4:5**(보유 이미지 실비율), 항목 `padding 12px 0`, 열 간격 20.
- 폼·상세는 `max-width 460px` 한 단(카트 행 문법 `.infoRows`).

## 6. 컴포넌트 문법

- **링크** = 밑줄 텍스트. 호버 `underline · offset 4.5px · thickness 0.8px`, 색 변화 없음.
  섹션 라벨은 소문자/국문 + ↗(8×8, ml 4px) — 링크가 아니면 화살표도 떼야 한다(2026-08-22).
- **버튼**은 없다. 유일한 채움 버튼 = 결제·제출 `.actionBtn`(잉크 채움, 종이색 글자, 13.2px, `padding 2px 6px`, 라운드 0).
  나머지 동작(주소 복사·채널 추가·저장)은 `.linkBtn` 밑줄 텍스트.
- **상태 표기**: 제품 = 좌상단 소문자 라벨 + 이미지 `opacity .45`(coming soon) / 정보 행 붉은 OUT OF STOCK(soldout).
  모임 = 반투명 블랙박스 오버레이 "sold out" / "coming soon". 저장·카트는 상태와 무관하게 가능.
- **컬러 칩** 11px 원 + 잉크 헤어라인, 이미지 바로 밑(2026-08-10 라운드 131).
- **캐러셀**: 원문 Swiper 문법 — `slidesPerView auto`, 간격 15, 전환 1000ms, 자동 2000ms(조작 후 지속),
  도트 8px 잉크(비활성 op .4, gap 8, 상단 25px). 세로 휠 하이재킹 없음. reduced-motion 정지.
- **캘린더**(일정): 칸 = `minmax(0,1fr)`, 칩 2줄 고정 `["레이지데이","4기-1회차"]`, 모바일 좌측 색 괘선 +
  투명 배경, 선택일 옅은 주황(α .11) + 날짜 800. 최대 3건/일.
- **모달**(이미지): 세로 드래그 탈출(96px 또는 0.55px/ms), 낱장은 전방향. 핀치줌 원본.
- **토스트** 하단 중앙 2.2초 — 미구현 기능은 지우지 않고 "준비 중" 토스트로 둔다(구성요소 전량 노출 원칙).
- **폼**: 이름·전화만(주소 미수집), 필수/선택 동의 분리, 실패 시 구제 원문 + 카카오톡 제출 경로.

## 7. 모션

규율(2026-08-10 M1~M3): **기존 요소만 움직인다 / 화면당 1모션·모션 없이 완결·1회성 / 무표정·발견형·
같은 농담 반복 금지.** `transform`·`opacity` 만, `prefers-reduced-motion` 은 전부 정지. 스크롤 스크럽·모프 남용·
전역 스무스 스크롤은 도입하지 않았다.

| 모션 | 규칙 |
|---|---|
| 첫 방문 인트로 | 4×4 워드서치 셔플 → LAZY·CLUB 빙고 써클, 5.0s, **탭 세션당 1회**(sessionStorage). 입력이 들어와도 끊지 않고 내비·푸터만 먼저 연다. 첫 페인트 전 인라인 가림막이 종이색으로 덮는다 |

## 8. 이미지·그래픽

- 이미지 최적화 꺼짐(`unoptimized`) — **소스 크기 = 전송량.** 최대 노출 ×2 로 축소해 커밋, 카드용/모달용 별도 파일.
- 규격: 후기 원본 세로 1440px webp q82 + 카드 가로 700px / 기수 포스터 800×1000 / 사람 400×577 /
  OG 1200×630(교체 시 파일명 버전업 — CDN 캐시) / 제품 사진은 밝은 배경 통일 권장.
- 톤 보정은 **종이색(히스토그램 피크)을 선형 게인으로** 맞춘다 — 중앙값·채널별 감마 금지(2026-09-02 실측).
- 그래픽 제작 층(`docs/redesign/07-graphic-system.md`): 지면 크림 `#F5F0E6`·잉크 `#1c1814` + 5색 중 2~3색,
  로고 1/4 타원호 요소 1회, 종이 텍스처·리소 그레인, 원칙 무문자. **UI 색이 아니다.**

## 9. 접근성·검증

- 색각·흑백에서 상태가 사라지지 않는다(§2). 날짜 셀은 `<button>`, `role=grid`·`aria-pressed`, 로딩 `role=status`.
- 검증 = 3뷰포트 스크린샷 + DOM 실측(`scripts/shot.mjs --eval`) + 배포 curl 마커. "됐을 것" 금지.
- 고정 요소 지도(겹침 사고 2회): 헤더 top / 토스트 bottom 18 / 거북이 트랙 sticky / 인트로·유휴 오버레이 z-200 / PreviewBar.

## 10. 북클럽 랜딩 시스템과의 관계

레이지데이 북클럽 랜딩(`app/(main)/lazyday`)은 **다른 옷**을 입는다 — 기수 모집이라는 서사가 있는 페이지라
콰이어트 에디토리얼(Aesop·The Row 결)로 확정됐다(2026-07). 두 시스템의 경계:

| | 레이지클럽 (§9) | 북클럽 랜딩 (§3) |
|---|---|---|
| 배경 | 오트 단일 `#f7f3ee` | 섹션 A `#f7f3ee` / B `#f0e9e0` **교차 필수**, 여백 없이 이어붙임 |
| 강조색 | 없음 | 브랜드 주황 `#d2691e`(CTA·괘선 56×1.5) |
| 서체 | Pretendard/SUIT/Gothic A1 | SUIT 기본, 책 본문만 Noto Serif KR 500 13px/1.85, 책 제목만 Pretendard 700 italic |
| 제목 | 13.2px 라벨 + ↗ | 32px/800 좌정렬 + 주황 괘선(≤480px 26px) |
| 버튼 | 텍스트 링크 | 주황 CTA·스티키 신청 버튼 |
| 모션 | 위 §7 | 섹션당 제목 1개 리빌(y12·0.9s), 히어로 숨 쉬는 포스터 |
| 검증 | 390/768/1280 | 390 모바일 퍼스트 |

관리 화면·회원 화면·결제 완료 이후 화면은 **레이지클럽 문법**이다(2026-09-01 "조회화면은 레이지클럽 베이스로").
결제 완료 화면(`/checkout/success`)만 예외로 어두운 북클럽 완료 화면(`#111009`)을 쓴다.
