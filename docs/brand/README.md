## 읽는 순서

새 세션·새 디자이너·새 운영 파트너 모두 **01 → 02 → 03** 순서로 읽는다.
01 이 없으면 02 의 "왜 유채색을 안 쓰는가"가 취향으로 보이고, 02 가 없으면 03 의
페이지들이 각자 다른 옷을 입는다.

## 유지 규칙

- 운영자 결정은 먼저 `docs/DECISIONS.md` 에 기록하고, 그 결정이 **정의를 바꾸면** 여기 반영한다.
  반대 순서(정의서만 고치기)는 금지 — 결정 로그가 근거다.
- 브랜드 카피·법률 문구는 운영자 소유. 이 문서에 인용된 원문은 **한 글자도 편집하지 않는다.**
- 이력 서술은 넣지 않는다(DECISIONS·git 이 맡는다). 여기엔 **현재 유효한 정의**만.
