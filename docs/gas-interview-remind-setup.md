# 전화 인터뷰 미예약 24h 리마인드 — GAS 적용 안내

전화 인터뷰를 신청하고 **24시간이 지나도록 일정을 제출하지 않은 사람**을 찾아,
운영자에게만 메일을 보냅니다. 메일에는 **그대로 복사해 카카오톡에 붙여넣을 안내 초안**이 들어가고,
초안의 가능 시간대(금일·익일·모레)는 발송 시점의 캘린더를 읽어 계산합니다.

> ⚠️ 신청자에게 자동 발송되는 것이 **아닙니다.** 초안을 만들어 드릴 뿐이고,
> 실제 발송은 운영자가 눈으로 한 번 보고 직접 합니다.

---

## 1. 무엇이 언제 오는가

| | |
|---|---|
| 수신 주소 | **contact@linkylounge.com** |
| 점검 시간 | 매일 **15:30 ~ 22:00**, 그 사이 **10분 간격** |
| 발송 조건 | 대상이 새로 생겼을 때만 (없으면 메일 없음) |
| 같은 사람에게 | **1회만** — 시트 `리마인드 발송` 칼럼에 기록해 재발송 안 함 |

10분 간격이라, 22시 전에 24시간을 넘긴 사람은 **10분 안에** 메일로 알려집니다.
22시~다음날 15:30 사이에 조건을 넘긴 사람은 **다음날 15:30**에 첫 점검에 잡힙니다.

## 2. 대상 판정

```
인터뷰 방식 = "전화 인터뷰"
그리고 '인터뷰 일시' 칸이 비어 있음        ← 예약하면 자동으로 채워지는 칸
그리고 '전화 인터뷰' 시트에 번호가 없음      ← 다른 번호로 예약한 경우 대비
그리고 신청일자로부터 24시간 경과
그리고 '리마인드 발송' 칸이 비어 있음        ← 1회 보장
```

### 자동으로 걸러내는 것 (메일 하단에 사유와 함께 표시)
- **이름** — `ㅇㅇ` `ㅁㄴㅇ` `ㅋㅋㅋ` `test` `테스트` 같은 입력, 내부 테스트 명단(`안동민`·`조세훈`)
- **나이** — 20세 미만 · 55세 초과
- **번호** — 010이 아니거나, `01000000000` 같은 반복·연속 번호

제외된 건도 메일 맨 아래에 사유와 함께 한 줄씩 보여드립니다. **오탐이 보이면 알려주세요** —
기준은 코드 상단 상수(`REMIND_TEST_NAMES`, `REMIND_AGE_MIN/MAX`) 한 줄만 고치면 됩니다.

## 3. 적용 절차

### ① 코드 붙여넣기
GAS 편집기에서 `linkyincdev-main.gs` 를 열고, **두 곳만** 반영합니다.
(전체 교체가 아닙니다 — 실배포본이 레포 사본보다 최신일 수 있어 최소 패치로 갑니다.)

1. **새 섹션 추가** — 레포 파일에서
   `// ═══ 전화 인터뷰 미예약 24h 리마인드 ═══` 부터
   `function enableInterviewReminder() { ... }` 끝까지를 통째로 복사해,
   `enableDailyBackup()` 함수 **바로 아래**에 붙여넣습니다.
2. **메뉴 2줄 추가** — 기존 `onOpen()` 안의 `.addItem("시트 서식·정리 (최초 1회)", ...)` **위에**:
   ```js
   .addSeparator()
   .addItem("지금 리마인드 점검 (미예약 24h)", "remindPendingNow")
   .addItem("자동 리마인드 켜기 (15:30~22:00)", "enableInterviewReminder")
   ```

### ② 배포
**배포 관리 → 기존 배포 편집 → 새 버전**
⚠️ **'새 배포'가 아닙니다.** 새로 배포하면 URL이 바뀌어 홈페이지 신청·예약이 전부 끊깁니다.

### ③ 즉시 테스트
스프레드시트를 새로고침 → 메뉴 **[레이지데이 관리] → [지금 리마인드 점검 (미예약 24h)]**
→ 결과 알림창이 뜨고, 대상이 있으면 contact@linkylounge.com 으로 메일이 갑니다.

이때 `신청현황` 시트 맨 오른쪽에 **`리마인드 발송` 칼럼이 자동으로 생깁니다.** 손댈 것 없습니다.

### ④ 자동 실행 켜기
메뉴 **[자동 리마인드 켜기 (15:30~22:00)]** 클릭 → 알림창 확인.

⚠️ **코드를 배포해도 자동 실행은 켜지지 않습니다.** 이 버튼을 한 번 눌러야 등록됩니다
(자동 백업과 똑같은 2단계입니다).

```

전화 인터뷰 신청 후 24시간이 지나도록 일정을 제출하지 않은 분이 2명 있습니다.
아래 초안을 그대로 복사해 카카오톡으로 보내시면 됩니다.
```

- **호칭**: 한글 3자 이름은 성을 뗍니다(`안동민` → `동민`). 2자·4자 이상·영문은 그대로.
- **가능 시간**: 평일 18:00–23:00 / 주말 13:00–23:00 중 예약·차단이 없고 **지금부터 2시간 넘게 남은** 30분 슬롯을 연속 구간으로 묶어 표기.
- 3일 모두 빈 경우 "가능한 시간을 확인해 다시 안내드리겠습니다."로 대체됩니다.

## 5. 알아두실 것

- **수기 예약**: 카톡으로 받은 예약을 캘린더에만 넣고 시트에 안 넣으셨다면 미예약으로 잡힙니다.
  자동 발송이 아니라 초안 제공이라 피해는 없지만, 보내기 전에 한 번 확인해 주세요.
- **슬롯 규칙이 두 곳에 있습니다** — 홈페이지 예약 화면(`apply/interview/schedule/page.tsx` 14~26행)과
  이 GAS 코드가 같은 값을 각자 들고 있습니다. **한쪽만 바꾸면** 안내한 시간에 신청자가 예약을 못 하는
  사고가 납니다. 시간대를 바꾸실 땐 두 곳 다 말씀해 주세요.
- **끄는 방법**: GAS 편집기 → 트리거(⏰) → `remindPendingInterviews` 삭제.
