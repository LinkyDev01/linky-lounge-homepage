# 디자인 토큰 v2 — 홈·일회성 (신문+바우하우스 언어)

v1.1 대비 변경: 단색 원칙 폐기 → 다색 팔레트, 모션 절 확정, 에셋 원칙 신설.
컬러·서체 값은 인스타 원본 실측 전 잠정치 — 실측 수령 즉시 교체.

## 0. 에셋 원칙 (최우선)

- 웹에서 도형·그래픽을 CSS로 그리지 않는다. 이미지 에셋으로 담는다
- 에셋은 전부 신규 제작한다. 재사용 가능한 원본 자산은 현재 없으며,
  인스타 피드는 소스가 아니라 스타일 레퍼런스다
- 낱장이 아니라 그래픽 시스템으로 제작: 구성 키트(팔레트 색면 도형, 질감 레이어,
  조판 규칙)를 정의해 신규 모임·신규 기수마다 조합으로 재생산 가능하게
- 스타일 4계열 (피드에서 계승): 신문 조판 / 바우하우스 기하 콜라주 /
  텍스트 아트 / 책 든 인물 사진 (사진만은 기존 촬영 문법 계속 사용)
- 질감(종이, 그레인, 인쇄 결)은 시스템의 질감 레이어로 제작. CSS 텍스처 흉내 금지
- 타인 템플릿·기성 포스터의 전재 금지 (상업 사이트 저작권 기준). 전부 오리지널
- 제작 경로: Claude Design(시스템·마스터 그래픽) + 이미지 생성 AI 보조(질감·변주),
  산출물은 코워크에서 규격화해 레포 public/assets/로

## 1. 컬러 — 다색, 규율 1개

규율: 색은 그래픽 블록·띠·스탬프·CTA 포인트에만. 텍스트는 잉크, 지면은 크림.

| 역할 | 잠정값 (실측 대체 예정) |
|---|---|
| 지면 크림 | #F5F0E6 / 밝은 면 #FBF8F1 |
| 잉크 (텍스트 전부) | #1c1814 / 본문 #4a3d30 / 보조 #8a7660 |
| 옐로 | #E9B32A (스탬프·포인트) |
| 레드 | #C7401F (CTA 언더라인·악센트) |
| 블루 | #2B5BC7 |
| 그린 | #7E9B82 |
| 라일락 | #C9AECB |

- 로고 색 재확정은 팔레트 실측 후 (기존 "#d2691e 교체" 결정은 보류로 전환)
- UI 요소(배경·버튼·보더)에 블루·그린·라일락 사용 금지 — 그래픽 안에서만

## 2. 서체

| 용도 | 방향 |
|---|---|
| 디스플레이 | 제호형 굵은 명조 계열. 후보: 마루 부리 굵은 웨이트 / 노토 세리프 KR 900 /
  조선일보명조·순명조 계열 검토. 인스타 실사용 서체 확인 후 최종 후보 확정 |
| 본문 | SUIT 또는 Pretendard (시안에서 결정) |
| 신문 요소(공고 박스 라벨 등) | 디스플레이와 동일 계열 축소 사용 |

- 위계는 크기·서체 전환으로만. 볼드는 문단 내 강조 한정

## 3. 타입 스케일 (유동)

- 히어로 헤드라인: clamp(40px, 9vw, 96px) / 행간 1.2 / keep-all
- 섹션 타이틀: clamp(28px, 4.5vw, 48px)
- 공고 박스 제목: 19~21px / 카드 제목: 15~17px 세리프
- 본문: 15.5px / 1.85, 폭 상한 65ch / 메타: 11~12px

## 4. 간격·레이아웃·괘선

- 간격 8px 배수 / 뷰포트 390·768·1280 / 그리드 4·8·12컬럼, 거터 24px, 최대 1120px
- 섹션 margin 금지, 배경 하드 컷
- 괘선 체계 (신문 문법): 굵은선 2~2.5px + 가는선 0.5~1px 이중선(대구분),
  가는선 단독(소구분), 박스 보더 1.5px 잉크
- 신문 제호 띠·"레이지데이 신문" 명판: 사용 안 함 (폐기 확정)

## 5. 모션 — 확정

스택: Lenis(스무스 스크롤) + GSAP ScrollTrigger·SplitText

기본 채택 9종:
1. 전역 스무스 스크롤
2. 히어로 로드 시퀀스 (내비→헤드라인→서브→CTA 순차)
3. 히어로 헤드라인 줄 단위 마스크 리빌 (어절 계단, 총 1.2s 이내, 최초 1회)
4. 히어로 하단 악센트 띠 그리기 (width 0→100%)
5. 시즌 공고: 괘선 그리기(scaleX) + 행 순차 리빌
6. 일회성 그리드: 열별 스태거드 진입 (계단 오프셋과 동조)
7. 카드 호버: translateY(-4px) + 보더 강조, 0.25s
8. 후기 마퀴: 저속(40~60s/루프), hover 일시정지
9. CTA 언더라인 애니 (hover, scaleX)

선택 2종 — 시안에서 온오프 비교 후 확정:
- 히어로 이탈 시차·페이드
- 브랜드 단락 줄별 차오름 (해당 단락 1곳 한정)

이연·금지:
- 핀 섹션 스크롤 전개 → 기수제 상세로 이연
- 스크롤 재킹, 텍스트 스크램블, 자동재생 영상 금지
- 신청 폼·FAQ 구간 정적 / prefers-reduced-motion 전면 대응
- transform·opacity 외 속성 금지 / 모션 오프 완결성 / 폰트 preload(LCP)
