# 디자인 토큰 v3 — 워크룸 이식판

원칙: 수치의 1차 출처는 08(원본 실측). 본 문서는 규율과 레이지데이 고유
결정만 정의하고, 실측으로 채워질 값은 [08]로 표기.

## 1. 색 — 도구적 절제

- UI 전면: 백지 배경 + 잉크 텍스트 (정확한 값 [08] 실측. 순흑/#111 계열 예상)
- 유채색 UI 사용 금지: 색은 콘텐츠 이미지(책 표지, 굿즈 사진, 그래픽)에서만 발생
  - **완화 (운영자 2026-08-04)**: 로고는 원본 3색 풀컬러 사용, "색을 지나치게
    제한할 필요 없다" — 단 유채색 UI 남발 금지 기조는 유지, 적용은 건별 판단
- 링크·호버 처리 방식 [08] 실측 따름 (밑줄/색 변화 여부)
- 기존 v2 팔레트(크림·5색)는 UI에서 퇴역, 07 그래픽 제작 팔레트로만 존속

## 2. 서체

- 원본 서체 스택 [08] 실측 → 동일 서체가 무료 사용 가능하면 채택,
  아니면 인상 최근접 무료 국문 고딕으로 대체하고 대체 사실을 08에 기록
- 세리프 디스플레이(마루 부리 등) 도입 건: 홈에서는 보류 (원문 문법이 고딕
  단일 체계). 브랜드 페이지·기수제 상세에서 재론
- 크기·행간·자간 전부 [08] 실측값 사용. 임의 스케일 발명 금지

## 3. 밀도·간격·괘선

- 컨테이너 폭, 거터, 섹션 여백, 리스트 행 높이, 라벨-제목 간격: [08]
- 괘선: 항목 상단 가는 흑선(두께 [08]), texts·shop 사이 세로 괘선
- 8px 배수 원칙은 실측값과 충돌 시 실측값 우선 (이식 충실도가 상위 규율)

## 4. 상호작용 (모션 v3 — 축소 재조정)

유지:
1. 전역 스무스 스크롤 (Lenis) — 질감 층, 유일한 전역 모션
2. 링크·리스트 항목 호버 (원본 방식 [08] 실측 재현 + 화살표 ↗ 문법)
3. 도서 캐러셀 조작 (드래그/휠 가로 스크롤, 점 페이지네이션)
4. 카드·이미지 호버 미세 반응 (0.2~0.3s, transform·opacity만)

이연 (기수제 상세·브랜드 페이지 후보로):
- 히어로 줄 리빌, 로드 시퀀스, 스태거드 진입, 마퀴, 줄별 차오름, 핀 섹션
- 사유: 워크룸 문법은 정적 인덱스가 본질. 홈에 진입 모션을 얹으면 이식
  충실도가 깨짐. 모션 극대화 지향은 서사가 있는 페이지(기수제 상세)로 이동

불변 조항: prefers-reduced-motion 대응 / 모션 오프 완결성 /
transform·opacity 외 금지 / 폰트 preload(LCP)
