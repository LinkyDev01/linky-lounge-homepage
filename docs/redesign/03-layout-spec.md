# 홈 상세 레이아웃 명세 v2 — 좌축 매거진 + 부분 오프셋 + 신문·바우하우스 구도

원리: 좌축은 법, 오프셋은 예외. 색과 그래픽은 에셋으로, 텍스트는 잉크로.
v1 대비 변경: 제호 띠 폐기, 시즌 모집=공고 박스, 히어로 우측=그래픽 자산 자리,
일회성 카드 2문법, 오렌지 단색 조항 삭제.

## 0. 전역 골격

- 축: 390px 마진 20px / 768px 마진 48px / 1280px 콘텐츠 1120px 중앙
- 그리드: 4 / 8 / 12컬럼, 거터 24px
- 오프셋 허용: ③일회성 그리드, ④브랜드/후기 2곳. 컬럼 이동으로만
- 1280px 한정: 축 좌측 바깥 세로쓰기 메타 1개
- 섹션 margin 없음, 배경 하드 컷. 지면은 크림 2단 교차(#F5F0E6/#FBF8F1 계열, 실측 후 확정)

## ① 히어로 — 오프셋 금지

- 내비: 좌 로고 / 우 메뉴 3개 텍스트 (제호 띠 없음)
- 좌측: 헤드라인(어절 줄바꿈 계단, 390px 3행 → 1280px 컬럼 1~7) + 서브 + CTA 텍스트 링크
- 우측(768px+): 그래픽 자산 자리 — 인스타 포스터·콜라주 원본 1점.
  CSS 도형 금지. 390px에서는 헤드라인 아래로 축소 배치 또는 생략 (시안 비교)
- 하단: 악센트 띠 8~12px 풀블리드 (색은 팔레트 실측 후 확정)

## ② 시즌 모집 — 신문 공고 박스, 오프셋 금지

- 형식: 잉크 1.5px 보더 박스. 헤더(제목 "4기 모집" + 상태 스탬프) / 본문 행
  (기간·요일·발제문, 가는 괘선 구분)
- 390px 행 세로 스택 → 768px+ 행 가로 분할
- CTA 텍스트 링크는 박스 하단 또는 직후, 축 정렬
- 대형 색면 카드 금지

## ③ 일회성 그리드 ("원데이 북토크") — 오프셋 구역 1

- 카드 2문법 병존:
  a) 인물 사진형 — 책 든 상반신 사진(기존 인스타 규격) 미디어 + 세리프 제목 + 메타
  b) 그래픽형 — 신규 제작 그래픽 미디어 + 동일 텍스트 구조
- 390px 1열(오프셋 해제) / 768px 2열 우측 +48px / 1280px 3열 계단 0·64·128px
- 뱃지 2단계: 모집중 / 마감
- 빈 상태: 문구가 아니라 "모집 알림 신청" 기능 블록 (이메일 입력 1필드 수준의
  최소 구현 — Code 범위에 추가)
- 하단 "전체 보기 →" 축 정렬
