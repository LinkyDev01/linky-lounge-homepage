# 홈 레이아웃 명세 v3 — 워크룸 이식 구조

원리: 홈은 홍보 페이지가 아니라 콘텐츠 인덱스다. 발명형 히어로 없음,
내비 아래 즉시 콘텐츠 시작. 구조·수치는 원본 차용(08), 콘텐츠는 전부 고유.

## 0. 페이지 구성 (위에서 아래로)

내비 → **⓪정규 독서모임 상품 모듈(2026-08-04 신설 — 좌 4기 포스터 / 우 상품명·
일정·브랜드 3문단, 모집 진입점 유일)** → ①도서 캐러셀 → ②meetings 리스트 +
③shop 사이드바 (합성 모듈) → 푸터. ②의 notice 고정 항목은 ⓪로 승격·제거

## 내비

- 좌: 로고 워드마크(텍스트 "lazyday press" 또는 국문 — 미결 연동) + 메뉴
- 우: search / login / cart 중 1차 구현은 search만 (login·cart는 커머스
  도입 전까지 미노출 — 기능 없는 메뉴 금지)
- 메뉴 명칭 (확정 2026-08-04): ?nav=ko|en 두 벌 구현, 기본 ko
  ko: **북클럽 / 원데이 클럽 / 브랜드** · en: books / meetings / about
- 보더 버튼 금지, 전부 텍스트 링크

## ① 도서 캐러셀 (섹션 라벨: 소문자 + ↗)

- 역대 기수 선정 도서 표지 가로 캐러셀 (1~4기 누적, 최신 우선)
- 표지 실판형 비율 유지, 풀블리드에 가까운 폭 [08], 점 페이지네이션
- 표지 클릭 → 해당 기수 아카이브 또는 도서 소개 (1차: 기수제 상세로 링크)
- 플레이스홀더 단계: 세로 판형 회색 12칸

## ② meetings 리스트 (좌 2열, 1280px 기준)

- 항목 구조: 상단 가는 괘선 / 소문자 카테고리 라벨 / 제목 (썸네일 필드는
  스키마 예약, 1차 미노출)
- 분류: notice / booktalk / lecture / reading / documents
- 첫 항목 고정: notice "레이지데이 북클럽 4기 멤버를 모집합니다." → 기수제 상세
- booktalk 항목: one-day-config.ts에서 로드, 뱃지 모집중/마감 2단계
- 빈 상태(예정 모임 없음): "모집 알림 신청" 블록 (이메일 1필드, 1차 목업)
- 데이터: one-day-config.ts { category, title, date, host, status, link }

## ③ shop 사이드바 (우 1열, 세로 괘선으로 ②와 분리)

- 굿즈: 코스터 1종, 머그 5색 — 사진 플레이스홀더 + 품명
- 가격 표기: 1차 미표기 (무상 제공 기조, 진열 목적). 커머스 도입 시 재론
- 1차에서 통째 생략도 가능하도록 컴포넌트 분리 구현

## 반응형 해제

- 1280: ②좌 2열 + ③우 1열 병치 / 768: ② 2열 유지, ③ 하단 이동 /
  390: 전부 세로 스택, 캐러셀은 가로 스와이프 유지
- 원본의 실제 해제 방식 [08] 실측과 대조해 조정

## 푸터

- 로고 mono-ink / 브랜드 소개(05의 브랜드 단락 1문단 발췌) /
  "About Lazyday Bookclub" 링크 → 브랜드 페이지 / 사업자 정보(기보유 약관
  체계 연동) / 인스타그램 텍스트 링크
