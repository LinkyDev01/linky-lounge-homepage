# 레퍼런스 지도 v3

## 0순위 — 구조 원본: workroompress.kr

- 역할: 홈 구조·수치의 단일 원본. 모든 레이아웃 판단은 이 사이트 실측(08)이 기준
- 사용 규칙: 눈대중 금지. curl로 CSS 실측 → 08 기입 → 구현 → 원본 캡처와
  나란히 대조 이미지 → 수치 단위 보정 지시 → 2~3회 루프
- 이식 윤리: 구조·조판 수치 차용은 관행 범위. 메뉴명·콘텐츠·이미지·문구는
  전부 레이지데이 고유로 채워 복제 시비를 원천 차단

## 1순위 — 콘텐츠 스타일: 인스타 @lazyday_bookclub 피드

- 역할: 워크룸 그릇에 담길 이미지 콘텐츠(그래픽·사진)의 스타일 기준 (07 연동)
- 책 든 인물 사진 규격은 계속 사용, 그래픽은 07 시스템으로 신규 제작

## 보조 (필요 시에만)

- Mobbin: 결제·신청 플로우 (기수제 상세·커머스 단계)
