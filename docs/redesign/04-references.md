# 레퍼런스 지도

## 반영 방법 3원칙 (모든 도구 공통)

1. 이미지 첨부: URL·이름만으로는 무효. 캡처를 파일로 직접 첨부
2. 속성 지정: 이미지당 가져올 속성 1~2개만 명시. "이런 느낌" 금지
3. 모사 강도 표기: 구조 모사 / 속성 이식 / (무드 참고는 금지)

검증 시에도 레퍼런스를 자로 사용: "레퍼런스 대비 헤드라인 스케일 부족, 1.3배" 식 수정 지시.

## 골격 층 레퍼런스 (조판·레이아웃)

**0순위 — 자체 기준선: 인스타 @lazyday_bookclub 피드**
| 자산 계열 | 웹 반영 |
|---|---|
| 신문 조판물 (괘선·공고·다단) | 시즌 공고 박스, 괘선 체계의 원형 |
| 바우하우스 포스터·콜라주 | 히어로 그래픽 자리, 그래픽형 카드 미디어 (원본 그대로 에셋화) |
| 텍스트 아트 (나선·다단 조판) | 브랜드 섹션·기수제 상세의 그래픽 후보 |
