# 카피 요소 17종 + 톤 규칙

브랜드 카피는 운영자 소유. 아래는 초안 요청·검수용 스펙.
확정 카피는 이 문서에 병기해 단일 출처화한다.

## 톤 규칙 — 확정 (현행 랜딩 '모임 소개' 심층분석 기반)

- 어미: 합쇼체 평서 단일. 해요체·청유·감탄 금지. 부정 선언("~하지 않습니다",
  "~가 아닙니다")로 경계 긋기(섹션당 1회 수준). 보조용언 완충("~어 봅니다/줍니다") 허용
- 인칭: 독자 직접 호명 금지("여러분"·"당신" 불가). 자격 규정형("~하는 사람들")으로
  간접 초대. 브랜드 자칭 "우리"(독자 포함형), "저희" 금지
- 어휘: 지적 한자어(사유·관점·궤적·화두·밀도) + 물성 고유어 동사(부딪히다·벼리다·
  빚어내다·엿보다) 배합. 은유 필드 4종: 직물(결) / 소리(불협화음) / 빛·시선(윤곽) / 금속(벼리다)
- 금지: 감탄사, 이모지, 과장 형용사, 자기계발 어휘, 마케팅 상투어(특별한·프리미엄·완벽한)
- 리듬: 장문 복문 뒤 단문 선언 교차. 강조는 볼드가 아니라 대구·역설 구조로
  (역설 = '불균형의 균형'의 문장형 구현)
- 층위: 상세 = 문체 원형(장문 허용) / 홈 = 같은 어휘 결, 문장 압축(장문 금지)
- 표기: "4기", 날짜 "9.7" / keep-all 기준 어절 줄바꿈 확인
- 홈에서 "신청" 단어 금지 (상세 페이지 소유)

## 요소 목록

공통: 1) 메뉴 3종(각 2~5자, 일회성 카테고리명 후보 3개) 2) 사이트 한 줄 소개(40자)
히어로: 3) 헤드라인(10~15자, 복수안) 4) 서브(20~30자) 5) CTA 라벨(6~10자, 기본 "4기 자세히 보기")
시즌: 6) 카드 제목(4~8자) 7) 보조 문구(15~25자, 발제문 중심)
일회성: 8) 섹션 타이틀(8~15자, 입구 역할·격하 금지) 9) 리드(20~35자)
  10) 마감 뱃지 형식 11) 빈 상태(15~25자) 12) 더보기 라벨(4~8자)

## 임시 카피 기준선 (초안 요청 시 방향·길이 기준, 확정 아님)

- 히어로 헤드라인: "게으른 속도로, 깊이 읽는 사람들"
- 히어로 서브: "레이지데이 북클럽 4기 — 두 달, 네 권, 한 테이블"
- CTA: "4기 자세히 보기"
- 시즌 보조: "모든 모임에는 발제문이 준비됩니다"

## 서사 순서 자산 (기수제 상세 개편 시 카피 골격)

써니사이드북 구조 분석에서 추출, 그릇(IA·조판)은 반면교사이므로 순서만 차용:
1) 감성 한 줄 선언 → 2) 공감 질문 연타 → 3) 큐레이션 신뢰(선정 도서+이유)
→ 4) 상품 구조화(두 달·4권·회차) → 5) 준비의 증거(발제문 실물)
→ 6) 후기 키워드화
반면교사 원칙: 페이지 직무 혼합 금지, CTA 소유권 분리, 볼드 남발 금지, 내비 이모지 금지
