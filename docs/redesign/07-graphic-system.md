# 그래픽 시스템 가이드 (G1) + Claude Design 제작 브리프 (G2용)

목적: 사이트용 오리지널 그래픽을 낱장이 아니라 시스템으로 제작한다.
피드는 스타일 레퍼런스, 소스는 전부 신규. 타인 템플릿 전재 금지.

## 1. 팔레트 (확정)

- 지면: 크림 #F5F0E6 (밝은 면 #FBF8F1)
- 잉크: #1c1814
- 색면 5색: 옐로 #E9B32A / 레드 #C7401F / 블루 #2B5BC7 / 그린 #7E9B82 / 라일락 #C9AECB
- 규칙: 한 그래픽당 색면 2~3색 + 잉크까지만. 5색 동시 사용 금지
  (색이 많아질수록 크림 여백 비중을 늘려 상쇄)

## 2. 도형 어휘

- 기본: 원, 사각, 삼각 (바우하우스 프리미티브)
- 시그니처: 로고의 1/4 타원호 — 대곡선 129:155 / 납작호 114:50 비율.
  모든 그래픽에 호 계열 요소 최소 1회 포함 (로고와의 혈연 표식)
- 선: 잉크 괘선(가는 선) 허용 — 신문 문법과의 접점

## 3. 구성 원칙 — 불균형의 균형

- 축 하나(수직 또는 수평)에 요소들을 정렬한 뒤, 한 요소만 축을 이탈시킨다
- 여백(크림 지면)이 전체의 30% 이상. 채우려는 충동 금지
- 대각 배치 허용, 회전 남발 금지 (기울기는 1요소까지)
- 요소 수 상한: 도형 5개 이내

## 4. 질감 — 도가의 자연스러움 담당 층

- 종이 텍스처 위 리소그래프풍 그레인
- 색면 가장자리의 미세한 인쇄 어긋남(1~2px 오프셋), 잉크의 불균일한 농도
- 금지: 매끈한 플랫 벡터 단독 노출, 그라데이션, 3D, 드롭섀도
  (지난 CSS 목업 실패의 원인이 질감 부재였음을 기준으로 삼는다)

## 5. 그래픽 내 텍스트

- 원칙적으로 무문자. 넣는 경우 명조 굵은 웨이트 국문만
- 의미 없는 장식 외국어 금지 (기존 피드의 덴마크어류 재발 방지)

## 6. 규격

| 용도 | 비율 | 제작 크기 |
|---|---|---|
| 히어로 그래픽 | 4:5 세로 | 1600×2000 |
| 카드 미디어(그래픽형) | 4:3 | 1200×900 |
| OG 이미지 | 1200×630 | 고정 |

- 포맷: PNG (질감 보존). 웹 최적화·WebP 변환은 G3(코워크)에서

## 7. 제작 목록 (G2)

- 히어로용 2점 (선택 1 채용, 1 예비)
- 카드 그래픽형 3점 (원데이 북토크용, 서로 다른 색면 조합으로 변주)
- OG 1점

# Claude Design 세션 붙여넣기용 브리프

[첨부 필수: 이 가이드 전문 + 인스타 피드 캡처 3장(바우하우스 포스터류) +
로고 SVG. 첨부 없이 실행 금지]

## 요청

독서모임 브랜드 "레이지데이 북클럽" 웹사이트용 오리지널 그래픽 6점을 제작한다.
첨부한 피드 캡처는 스타일 방향의 증거이며, 그 안의 요소를 복제하지 않는다.
위 가이드의 팔레트·도형 어휘·구성 원칙·질감 규칙을 전 항목 준수한다.

- 히어로 그래픽 2점 (4:5): 바우하우스 기하 구성, 로고 1/4 호 요소 포함,
  무문자, 종이+그레인 질감
- 카드 그래픽 3점 (4:3): 동일 시스템의 소형 변주, 각기 다른 2~3색 조합
- OG 1점 (1200×630): 좌측에 국문 명조 텍스트 자리(빈 영역으로) 확보,
  우측 그래픽 구성

## 검수 기준 (산출물마다 자가 확인 후 제출)

- 색면 2~3색 + 잉크 이내인가 / 여백 30% 이상인가
- 1/4 호 요소가 있는가 / 축 정렬 + 1요소 이탈 구조인가
- 질감이 있는가 (플랫 벡터 단독 아님) / 텍스트·외국어가 없는가

## 반복 방식

1차 산출 후 수정 지시는 "3번 카드: 레드 면적 축소, 호 요소를 우상단으로" 식의
요소 단위로 진행한다. 전체 재생성 금지.
