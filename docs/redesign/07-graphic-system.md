# 그래픽 시스템 — 콘텐츠 제작 층 (v3 재정의)

v3에서의 위치: 홈 UI는 백지+잉크(02)이므로 이 시스템은 화면 스타일이 아니라
콘텐츠 이미지 제작 규정이다. 산출물은 meetings 썸네일(2차), 모임 포스터,
OG, 인스타 게시물에 쓰인다. 우선순위는 도서 표지 수집(C1)·굿즈 촬영(C2)보다
뒤 (플레이스홀더 교체 순서: 표지 → 굿즈 → 그래픽).

## 팔레트 (그래픽 내부 전용 — UI 사용 금지)

- 지면 크림 #F5F0E6 / 잉크 #1c1814
- 색면 5색: 옐로 #E9B32A / 레드 #C7401F / 블루 #2B5BC7 / 그린 #7E9B82 /
  라일락 #C9AECB — 한 점당 2~3색 + 잉크까지만

## 도형 어휘 (로고 호 라벨 정정판)

- 기본: 원, 사각, 삼각 + 잉크 가는 괘선
- 시그니처: 로고 1/4 타원호 — 정본 명세:
  그린 기둥 91:95 / 브라운 스우시 r86(정원) / D 외곽 대곡선 129:155 /
  D 우하단 납작호 114:50 / D 좌하단 r48 / 카운터 85:113
  (114:50은 오렌지 D 우하단이다 — 브라운 아님. 이전 라벨 누락 정정)
- 모든 그래픽에 호 계열 요소 최소 1회

## 구성·질감·텍스트 (유지)

- 축 정렬 + 1요소 이탈(불균형의 균형), 여백 30%+, 도형 5개 이내, 기울기 1요소
- 종이 텍스처 + 리소 그레인 + 1~2px 인쇄 어긋남. 플랫 벡터 단독·그라데이션·
  3D·드롭섀도 금지
- 원칙 무문자. 필요 시 국문 명조만. 의미 없는 외국어 금지
- 타인 템플릿 전재 금지, 전부 오리지널

## 규격

| 용도 | 비율 | 제작 크기 |
|---|---|---|
| 모임 포스터·인스타 | 4:5 | 1600×2000 |
| meetings 썸네일 | 1:1 | 800×800 |
| OG | 1200×630 | 고정 |
