# 하위 페이지 기획 v1 (2026-08-04, 홈 v3 후속)

> **구현 현황 (라운드 10)**: 1~4순위 구현 완료 — 원데이 상세 2종·굿즈 상세
> 3종·목록(필터)·카트(localStorage). 5(브랜드)·6(로그인)은 안내 토스트 상태.
> 상태 3단계(open/soldout/upcoming) + 오버레이 마킹 추가.

원칙: 워크룸 해당 페이지를 실측해 구조 차용(08 방식), 콘텐츠·동선은 레이지데이
고유. 구성요소는 전량 배치하고 미구현 기능은 안내 토스트(라운드 8 원칙).
주소 등 불필요 정보는 어떤 단계에서도 수집하지 않는다(라운드 7 결정).

## 우선순위와 라우트 (프리뷰 트리 기준)

| 순서 | 라우트 | 원문 대응 | 핵심 구성 |
|---|---|---|---|
| 1 | `preview/home-v3-workroom/meetings/[slug]` — 원데이 토크 상세 | 상품 상세(texts형: 이미지 1/8 + summary 11/15) | 카드 이미지 스택 / 카테고리·제목 36px·설명(도록체)·일시·장소·진행·인원·문의·가격 / 구매하기(→ 원데이 apply)·카트 담기·저장 / 관련 항목(related) |
| 2 | `…/shop/[slug]` — 굿즈 상세 | 상품 상세(shop형) | 사진 스택 / 품명·설명·가격(추후)·구매(안내)·카트·저장 |
| 3 | `…/meetings` — 원데이 클럽 목록 | texts 카테고리 아카이브 | 카테고리 필터(notice/booktalk/…) + 리스트(홈 항목 문법 재사용) + 더보기 |
| 4 | `…/cart` — 장바구니 | WooCommerce cart | 로컬 카트(localStorage): 담은 항목·수량·합계 → "주문하기" = 이름·전화만 받는 티켓형 결제(주소 없음) |
| 5 | `…/brand` — 브랜드 페이지 | 없음(자체) | 이월 카피 자산(05): 헤드라인·결·클로징 + 브랜드 3문단 전문. About 링크의 목적지 |
| 6 | `…/login` — 로그인 | Ultimate Member | 소셜(카카오 우선) 목업 → 실구현은 커머스 로드맵 5단계 |

## 데이터

- 원데이·굿즈 상세 = `one-day-config.ts` 확장(설명·이미지 스택·가격·정원 필드
  추가) + `GOODS` 승격. 홈 리스트와 단일 출처 공유
- 카트 = localStorage `lazyday_cart` (회원 도입 전까지). 저장(북마크) =
  localStorage `lazyday_saved` — 이 단계에서 실동작 전환 가능

## 결제 원칙 (라운드 7 확정)

- 워크룸식 '상품화 부조화'는 상세 페이지 문법(가격·구매·카트)으로 유지
- 결제 입력은 이름·전화번호만 — 기존 원데이 접수(GAS)+계좌/토스 흐름 재사용,
  PG 위젯 승격은 커머스 로드맵 4단계

## 검수

- [ ] 상세 페이지 여백 = 원문 실측(이미지 1/8·텍스트 11/15·제목 36px)
- [ ] "신청" 단어는 상세 페이지에서도 금지(구매하기로 통일), 주소 입력 0
- [ ] 구성요소 전량 + 미구현 안내 토스트 일관
