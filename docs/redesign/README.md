## 작업 파이프라인 (현재 위치 표시)

1. IA·레이아웃 확정 — 완료 (03, 홈 한정)
2. 토큰 v1.1 — 완료, 모션 절 제외 (02)
3. 모션 확정·02 병합 — 완료
4. 카피 확정 v1.1 — 완료 (05)
5. **부트스트랩 → Code 프리뷰 제로베이스 시안 2~3안 — 다음 작업** (`app/(main)/lazyday/preview/home-v3/`)
6. 정적 골격 승인 → 모션 레이어 구현
7. 일회성 모임 목록·상세 레이아웃 명세 작성 (03 확장, 홈 확정 문법 기반)
8. 홈 실사이트 이식 → 일회성 모임 구현 → 기수제 상세 확산
   (기수제 상세 카피 구조는 05의 서사 순서 자산 활용)

병행 트랙 — 그래픽 시스템 제작 (블로커 아님, Code 시안은 플레이스홀더로 선진행):
G1. 그래픽 스타일 가이드 — 완료 (07)
G2. 마스터 그래픽 제작 (Claude Design 주도 + 생성 AI 보조): 히어로용 1~2점,
    그래픽형 카드용 3점, OG 이미지
G3. 코워크에서 웹 규격화 → Code 시안의 플레이스홀더 교체
